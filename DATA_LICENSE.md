# Licença e atribuição dos dados

Os dados de origem pertencem às demonstrações financeiras públicas entregues pela Magazine Luiza S.A. e disponibilizadas pelo Portal de Dados Abertos da Comissão de Valores Mobiliários (CVM).

O conjunto DFP é identificado no portal sob a **Open Data Commons Open Database License (ODbL) 1.0**. A camada derivada em `data/processed/` é disponibilizada sob os mesmos termos aplicáveis à base de dados.

- Conjunto DFP: https://dados.cvm.gov.br/dataset/cia_aberta-doc-dfp
- Termos do portal: https://dados.cvm.gov.br/about
- Texto da ODbL 1.0: https://opendatacommons.org/licenses/odbl/1-0/
